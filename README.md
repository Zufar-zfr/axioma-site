# Аксиома — сайт

Статический сайт (HTML/CSS/JS), сборка не нужна: откройте `index.html`.

- `index.html` — главная (вращающаяся Земля, портфолио, услуги, о компании)
- `agents.html` — страница ИИ-агентов с демо-чатом
- `config.js` — настройки (адрес API чата)
- `script.js` — Земля (three.js), анимации, ссылки WhatsApp / проектов (константы вверху)
- `chat.js` — чат-виджет

## Подключение API чата

В `config.js` укажите `chatApiUrl`. Пока он пустой, отвечает локальный демо-сценарий.

Запрос:

```http
POST {chatApiUrl}
Content-Type: application/json

{ "sessionId": "uuid", "message": "текст клиента", "history": [{"role":"user|assistant","content":"..."}] }
```

Ответ `200`:

```json
{ "reply": "текст агента", "crm": { "topic": "…", "contact": "…", "status": "…" } }
```

`crm` необязателен — заполняет карточку «Что видит менеджер» на странице агентов.
Для вызова с сайта на другом домене на API нужен CORS. Ключи моделей храните только на сервере.
